# Akshat Saxena — Developer Portfolio

A responsive, dark-first portfolio for GitHub Pages.

## Deploy
1. Keep `index.html`, `script.js`, `tailwind.config.js`, and the `img/` folder together.
2. Push the contents of this folder to the repository's GitHub Pages branch.
3. In repository Settings → Pages, select the correct branch and root folder if needed.

The site uses Tailwind CSS via CDN and Google Fonts, so those require an internet connection. The contact form uses Web3Forms; verify its access key is active before relying on submissions.
